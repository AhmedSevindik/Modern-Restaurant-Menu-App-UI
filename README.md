# 🍽️ Modern Restaurant Menu App UI

Modern Flutter restaurant application with
clean architecture and reusable UI components.

## ✨ Features

- Dark Theme
- Responsive Layout
- Reusable Widgets
- Modern UI
- Food Cards
- Search System
- Scalable Architecture
